# 2026-08-20 DailyLog

## 오늘 배운것 

### Cookie, Session, ServeletContext, setAttribute, ServletConfig, loadOnStartup

- cookie : 브라우저에 저장 (브라우저에 있는 내 사원증 느낌)
- Session : 서버에 사용자별 데이터 저장 (회사의 개인 사물함 느낌)
- ServletContext : 웹 애플리케이션 전체가 공유 (회사 전체 공용 게시판 느낌)
- ServletConfig : 특정 Servlet의 설정 (직원 개인 업무 메뉴얼 느낌)
- loadOnStartup : 서버 시작시 Servlet을 미리 초기화  (회사가 문 열기 전 직원 미리 출근)

## 핵심 연결 
```
                 웹 애플리케이션
                      │
      ┌───────────────┼────────────────┐
      │               │                │
      ↓               ↓                ↓
    공용 게시판     개인 사물함     직원
 ServletContext       Session       Servlet
                                         │
                              ┌──────────┴─────────┐
                              ↓                    ↓
                        개인 업무설정            미리 출근
                        ServletConfig       load-on-startup
```
