MVC  -> 구조 익히기 
model   :  브라우저로 응답할 데이터 (VO ,DAO)                   <- 직원 (넵 가져오겠습니다!)
views    :   요청한 브라우저로 응답할 디자인 화면 (HTML, JSP)
controll :  Model과 view 연결해주는 중간 관리자 (서블릿)   <- 사장 (조회해서 가꼬와~)


-클라이언트의 파일첨부 후 업로드 요청하는 디자인 VIEW(WEB-INF/views/fileUpload.jsp) 흐름-

파일 업로드용 form 태그에서 반드시 지켜야할 3가지 
1.method="post"

2.enctype="multipart/form-data"

3.action="upload.do"

중복되는 @WebServlet("_____") 가 있으면 서버자체가 start 안됨 
----------------------------------------------------------
new DefaultFileRenamePolicy -> 파일뒤에 자동으로 1, 2, 3, 4 ...... 붙혀줌 
----------------------------------------------------------
서블릿이 하는일 
1. 브라우저가 보낸 요청 데이터 request 내장객체 메모리에서 꺼낸다
2. Model (DAO) 에게 DB작업을 시키고 결과받는다
3. 결과를 request 내장객체 메모리에 바인딩하고 View (JSP) 에게 화면 그리라고 함
----------------------------------------------------------
Controller 가 하지 않는일
1.SQL 문장작성 -> Model (DAO) 가 함
2.HTML 태그 출력 -> View (JSP) 가 함
----------------------------------------------------------
GET 방식이 되는경우 3가지 
POST 방식이 되는 경우 3가지
