# JSP 파일 다운로드 흐름 정리

## 1. 파일 다운로드란?

파일 다운로드는 **서버에 저장되어 있는 파일을 사용자의 컴퓨터로 전송하는 과정**이다.

쉽게 말하면:

서버 → Servlet → 브라우저 → 사용자 PC

---

## 2. 파일 다운로드 전체 흐름

```text
사용자
  ↓
다운로드 버튼 클릭
  ↓
Servlet으로 다운로드 요청
  ↓
Servlet에서 다운로드할 파일 정보 확인
  ↓
서버에서 파일 찾기
  ↓
InputStream으로 파일 읽기
  ↓
OutputStream으로 Response에 파일 쓰기
  ↓
브라우저
  ↓
사용자 PC에 파일 다운로드
