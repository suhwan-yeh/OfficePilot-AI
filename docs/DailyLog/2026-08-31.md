## 1. 표현 언어(EL)이란?

EL(Expression Language)은 JSP에서 Java 코드를 직접 작성하지 않고도 객체나 속성 값을 쉽게 가져와 출력하거나 연산할 수 있도록 제공하는 표현 언어이다.

기본 문법은 ${}를 사용한다.

예시:

    ${name}
    ${10 + 1}
    ${user.name}

Servlet에서 데이터를 바인딩할 수 있다.

    request.setAttribute("name", "홍길동");

JSP에서는 EL을 이용해 값을 출력할 수 있다.

    ${name}

결과:

    홍길동

즉,

Servlet에서 데이터를 저장
→ JSP로 전달
→ EL을 이용해 데이터를 꺼내서 출력

하는 구조이다.

---

## 2. EL의 기본 동작 구조

EL 자체만 외우기보다는 Servlet과 JSP가 어떻게 연결되는지 이해하는 것이 중요하다.

    브라우저
       ↓ 요청
    Servlet
       ↓ 데이터 처리
    request / session / application에 데이터 저장
       ↓ forward()
    JSP
       ↓ EL ${}
    데이터 출력
       ↓
    브라우저 화면

Servlet은 주로 데이터를 처리하고 준비하는 역할을 하고,
JSP는 준비된 데이터를 화면에 출력하는 역할을 한다.

---

## 3. 바인딩과 EL

Servlet에서 setAttribute()를 이용하면 특정 영역에 데이터를 이름과 함께 저장할 수 있다.

    request.setAttribute("id", "hong");
    request.setAttribute("pwd", "1234");

    session.setAttribute("name", "홍길동");

    application.setAttribute("email", "hong@test.com");

각 영역에 저장된 데이터는 다음과 같다.

    request
     ├─ id  → hong
     └─ pwd → 1234

    session
     └─ name → 홍길동

    application
     └─ email → hong@test.com

JSP에서는 EL을 사용해서 값을 가져올 수 있다.

    ${id}
    ${pwd}
    ${name}
    ${email}

---

## 4. request / session / application의 차이

### request

하나의 요청 동안 데이터를 저장한다.

    request.setAttribute("id", "hong");

JSP:

    ${id}

---

### session

한 사용자의 세션 동안 데이터를 유지한다.

    session.setAttribute("name", "홍길동");

JSP:

    ${name}

로그인 사용자 정보처럼 여러 페이지에서 계속 사용할 데이터에 활용할 수 있다.

---

### application

웹 애플리케이션 전체에서 공유되는 데이터를 저장한다.

    application.setAttribute("email", "hong@test.com");

JSP:

    ${email}

애플리케이션 전체에서 공통적으로 사용하는 데이터에 활용할 수 있다.

---

## 5. JSP로 forward하기

Servlet에서 데이터를 준비한 뒤 JSP에게 화면 출력을 맡길 수 있다.

    RequestDispatcher rd =
        request.getRequestDispatcher("member1.jsp");

    rd.forward(request, response);

forward()는 현재 사용 중인 request와 response를 그대로 JSP에게 전달한다.

즉,

    Servlet
       ↓
    request에 데이터 저장
       ↓
    forward(request, response)
       ↓
    member1.jsp

의 흐름으로 동작한다.

따라서 Servlet에서:

    request.setAttribute("id", "hong");

라고 저장한 데이터를 member1.jsp에서:

    ${id}

로 출력할 수 있다.

### forward의 핵심

    rd.forward(request, response);

는

"현재 요청(request)과 응답(response)을 그대로 가지고 member1.jsp로 넘어가라."

라는 의미이다.

즉 Servlet과 JSP가 같은 request와 response를 이어서 사용하는 것을 "request, response 객체를 공유한다"고 표현한다.

---

## 6. EL에서 값 출력하기

### 숫자

    ${100}

결과:

    100

### 문자열

    ${"안녕하세요"}

결과:

    안녕하세요

### 숫자 연산

    ${10 + 1}

결과:

    11

EL에서는 단순히 값을 출력하는 것뿐만 아니라 간단한 연산도 할 수 있다.

---

## 7. 객체의 속성 출력하기

Servlet에서 객체를 바인딩할 수도 있다.

    request.setAttribute("user", user);

JSP에서는:

    ${user.name}
    ${user.age}

와 같이 객체의 속성에 접근할 수 있다.

예를 들어 User 객체에 name과 age가 있고 getter가 있다면:

    ${user.name}
    ${user.age}

와 같이 사용할 수 있다.

EL의 객체 속성 접근은 Java의 getter와 연결해서 이해하면 쉽다.

    ${user.name}

는 개념적으로

    user.getName()

과 같은 방식으로 생각할 수 있다.

---

## 8. EL과 기존 JSP 표현식 비교

기존 JSP에서는 Java 코드를 이용해 값을 출력할 수 있었다.

    <%
        String name = (String)request.getAttribute("name");
    %>

    <%= name %>

EL을 사용하면 훨씬 간단하게 표현할 수 있다.

    ${name}

따라서 EL을 사용하면 JSP 페이지에 Java 코드를 직접 작성하는 것을 줄이고 화면 출력 코드를 간결하게 만들 수 있다.

---

## 9. EL 내장 객체(내장 변수)

EL에서는 JSP의 여러 영역에 접근하기 위한 내장 객체를 제공한다.

대표적인 Scope 관련 내장 객체:

    pageScope
    requestScope
    sessionScope
    applicationScope

예를 들어 request 영역에 저장된 데이터를 명확하게 가져오려면:

    ${requestScope.id}

session 영역이라면:

    ${sessionScope.name}

application 영역이라면:

    ${applicationScope.email}

과 같이 사용할 수 있다.

---

## 10. Scope와 EL 연결

EL에서 단순히:

    ${name}

이라고 작성하면 해당 이름의 속성을 Scope에서 찾아간다.

특정 Scope를 직접 지정할 수도 있다.

    ${requestScope.name}
    ${sessionScope.name}
    ${applicationScope.name}

따라서 Scope를 명확하게 지정하면 어느 저장 영역의 데이터를 사용하는지 쉽게 알 수 있다.

---

## 11. EL Syntax Error

EL을 사용할 때 문법이 잘못되면 Syntax Error가 발생할 수 있다.

EL은 기본적으로 ${} 형태를 사용한다.

    ${name}

EL의 시작과 끝을 정확하게 작성해야 하며,
문자열이나 연산식도 EL 문법에 맞게 작성해야 한다.

또한 Eclipse에서 빨간 줄이 표시되더라도 실제 Tomcat에서 JSP가 정상적으로 실행되는 경우가 있다.

따라서:

    Eclipse의 문법 검사 오류
    ≠
    실제 JSP 실행 오류

일 수 있다는 것을 확인했다.

## 12. 오늘 배운 내용 전체 연결

오늘 배운 내용을 하나의 흐름으로 정리하면 다음과 같다.

    브라우저
       ↓
    Servlet 요청
       ↓
    Servlet에서 데이터 처리
       ↓
    setAttribute()
       ↓
    request / session / application에 데이터 바인딩
       ↓
    forward(request, response)
       ↓
    JSP
       ↓
    EL ${}
       ↓
    바인딩된 데이터 출력
       ↓
    브라우저

예시:

    request.setAttribute("id", "hong");
    request.setAttribute("pwd", "1234");

    session.setAttribute("name", "홍길동");

    application.setAttribute("email", "hong@test.com");

    RequestDispatcher rd =
        request.getRequestDispatcher("member1.jsp");

    rd.forward(request, response);

JSP:

    ${id}
    ${pwd}
    ${name}
    ${email}

결과:

    hong
    1234
    홍길동
    hong@test.com

## 13. OfficePilot-AI와 연결

OfficePilot-AI에서도 Servlet과 JSP를 사용한다면 Servlet에서 업무 데이터를 준비하고 JSP에서 EL을 이용해 화면에 출력하는 구조로 활용할 수 있다.

예를 들어 로그인한 사용자의 정보를 Servlet에서 준비한다.

    request.setAttribute("userName", "홍길동");
    request.setAttribute("department", "개발팀");

JSP에서는:

    <h2>안녕하세요, ${userName}님</h2>
    <p>부서 : ${department}</p>

와 같이 출력할 수 있다.

업무 데이터도 같은 방식으로 연결할 수 있다.

    Servlet
       ↓
    업무 데이터 조회
       ↓
    request.setAttribute()
       ↓
    JSP
       ↓
    EL ${}
       ↓
    화면에 업무 정보 출력

향후 Spring Boot를 사용하게 되더라도 Controller에서 데이터를 준비하고 View에 전달한다는 구조를 이해하는 데 도움이 된다.

## 14. 오늘의 핵심 정리

### EL

    EL = Expression Language

JSP에서 데이터를 쉽게 표현하고 출력하기 위한 언어이다.

기본 문법:

    ${값}

---

### setAttribute()

    request.setAttribute("id", "hong");

특정 Scope에 데이터를 이름과 함께 저장한다.

---

### forward()

    rd.forward(request, response);

현재 request와 response를 유지하면서 JSP로 요청 처리를 넘긴다.

---

### EL로 데이터 출력

    ${id}

바인딩된 id 값을 가져온다.

---

### Scope

    request
    session
    application

각각 데이터가 유지되는 범위가 다르다.

---
