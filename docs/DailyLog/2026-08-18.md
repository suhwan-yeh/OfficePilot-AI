# JSP & Servlet 학습 정리

## 1. 오늘 학습한 내용

### JSP

JSP(JavaServer Pages)는 웹 페이지를 동적으로 생성하기 위한 기술이다.

HTML 코드 안에서 Java 기반의 동적인 처리를 할 수 있으며, 사용자가 보는 **웹 화면(View)** 을 구성하는 데 활용할 수 있다.

### Servlet

Servlet은 클라이언트의 요청을 받아 Java 코드로 처리하는 서버 측 프로그램이다.

예를 들어 사용자가 로그인이나 일정 등록과 같은 요청을 보내면 Servlet이 요청을 받아 필요한 작업을 처리할 수 있다.

### JSP와 Servlet의 관계

```text
사용자
 ↓
JSP 화면
 ↓ 요청
Servlet
 ↓
Java 로직 처리
 ↓
DB
 ↓
Servlet
 ↓
JSP 화면에 결과 출력
```

JSP는 주로 **화면을 담당**하고, Servlet은 **요청과 처리 로직을 담당**한다고 이해했다.

## 2. OfficePilot-AI에 적용한다면

OfficePilot-AI는 AI 비서 서비스이기 때문에 사용자가 웹 화면에서 AI 비서에게 명령을 내리고 그 결과를 확인하는 구조가 필요하다.

예를 들어 사용자가

> "내일 오전 10시에 회의 일정 추가해줘."

라고 요청한다고 가정한다.

현재 학습한 JSP와 Servlet 개념으로 연결하면:

```text
사용자
 ↓
JSP
AI 비서 화면
 ↓
Servlet
사용자 요청 전달
 ↓
Java 로직
요청 분석 및 처리
 ↓
DB
일정 저장
 ↓
JSP
처리 결과 표시
```

현재는 JSP와 Servlet을 학습하는 단계이므로 위와 같은 **웹 요청 → Java 처리 → DB → 화면 출력** 구조를 이해하는 데 활용할 수 있다.

---

## 3. 앞으로 배울 Spring과의 연결

JSP와 Servlet에서 배운 구조는 이후 Spring을 공부할 때 기초가 된다.

```text
현재 학습

JSP
 ↓
Servlet
 ↓
Java
 ↓
DB


Spring 학습 후

JSP/Frontend
 ↓
Controller
 ↓
Service
 ↓
Repository
 ↓
DB
```

따라서 오늘 배운 JSP와 Servlet은 OfficePilot-AI를 직접 완성하는 기술이라기보다, **웹 애플리케이션에서 사용자의 요청이 서버와 DB까지 어떻게 전달되는지 이해하기 위한 기초 개념**으로 연결한다.

---

## 4. OfficePilot-AI에서의 활용 아이디어

* AI 비서 웹 화면 구성
* 로그인 및 회원 관리 화면
* 일정 등록/조회/수정/삭제 화면
* 업무 관리 화면
* AI 요청 및 응답 결과 표시
* 서버와 DB 사이의 요청 흐름 이해

### 오늘의 핵심

> **JSP = 사용자에게 보여주는 화면**

> **Servlet = 사용자의 요청을 받아 Java로 처리**

> **OfficePilot-AI에서는 웹 화면 → 서버 → DB로 이어지는 구조를 이해하는 기초 기술로 연결**

향후 Spring을 배우면서 JSP/Servlet에서 이해한 요청 처리 구조를 **Spring MVC 구조로 발전시켜 OfficePilot-AI에 적용한다.**
