## 프로젝트 보충 - 렌터카 사이트 요청/응답 흐름 정리

오늘은 렌터카 사이트를 직접 만들어보면서 JSP/Servlet 구조와
클라이언트의 요청부터 DB 조회 후 화면에 응답되는 전체 흐름을 복습함.

강사님이 대부분의 코드를 제공해주셨기 때문에 코드를 전부 외우기보다는
**각 계층이 어떤 역할을 하고 데이터가 어떻게 이동하는지**를 중심 정리.

---

## 1. 전체 흐름

```text
👤 클라이언트
    ↓ 요청(Request)
🖥️ 화면(JSP)
    ↓
👨‍💼 Controller(Servlet)
    ↓
🧑‍💼 Service
    ↓
🧑‍💼 DAO
    ↓
🗄️ DB
    ↓
🧑‍💼 DAO
    ↓
🧑‍💼 Service
    ↓
👨‍💼 Controller(Servlet)
    ↓
🖥️ 화면 응답(Response)
    ↓
👤 클라이언트
```

### 각 역할

* **JSP** → 사용자에게 화면을 보여주고 요청을 보냄
* **Controller(Servlet)** → 클라이언트의 요청을 받고 다음 작업을 연결
* **Service** → 실제 업무 로직 처리
* **DAO** → DB에 접근해서 데이터를 조회/저장
* **DB** → 실제 데이터 저장 및 조회
* **Controller → JSP** → 처리 결과를 화면에 전달

---

## 2. 오늘 꼭 기억할 필수 코드

### ① Controller에서 Service 호출

```java
CarService service = new CarService();

List<CarVO> carList = service.getCarList();
```

Controller가 직접 DB 작업을 하는 것이 아니라

**Controller → Service → DAO**

순서로 업무를 처리한다.

---

### ② Service에서 DAO 호출

```java
CarDAO dao = new CarDAO();

List<CarVO> carList = dao.selectCarList();
```

Service는 필요한 업무를 처리하고 DAO에게 DB 작업을 요청한다.

---

### ③ Controller에서 JSP로 데이터 전달

```java
request.setAttribute("carList", carList);

request.getRequestDispatcher("carList.jsp")
       .forward(request, response);
```

DB에서 가져온 데이터를 JSP에서 사용할 수 있도록
**request에 바인딩한 후 forward()로 JSP에 전달**한다.

JSP에서는 EL을 사용해서 데이터를 꺼낼 수 있다.

```jsp
${carList}
```

---

## 3. 핵심 개념

### 가장 중요한 흐름

```text
클라이언트 요청
 ↓
Controller
 ↓
Service
 ↓
DAO
 ↓
DB
 ↓
DAO
 ↓
Service
 ↓
Controller
 ↓
JSP
 ↓
클라이언트 응답
```

### 한 줄 정리

> **Controller는 요청을 받고, Service는 업무를 처리하고, DAO는 DB를 담당한다.**

---

## 4. 총정리 ㄱㄱ

오늘 렌터카 사이트를 직접 만들어보면서 단순히 코드를 작성하는 것보다
**각 코드가 왜 존재하고 어느 계층에서 실행되는지 이해하는 것이 중요하다는 것을 느낌.**

아직 모든 코드를 직접 작성할 정도는 아니지만,

**Controller → Service → DAO → DB → Service → Controller → JSP**

라는 큰 흐름은 확실하게 이해하고 넘어가는 것을 목표로 공부했음 

앞으로도 Spring Boot 배울꺼니까 Spring Boot를 배울 때도 이 구조가
**Controller → Service → Repository** 형태로 연결된다는 점을 기억하면서 공부할것.

## JAVA / JSTL / EL 언어의 차이 

```
- Java
→ 실제 프로그램 로직을 처리하는 언어
→ 계산, 조건, 반복, DB 처리 등
→ 주로 Controller / Service / DAO에서 사용

- JSTL
→ JSP에서 조건문, 반복문 등을 태그로 처리하는 라이브러리
→ <c:if>, <c:forEach> 등
→ 화면을 만들 때 사용

- EL
→ JSP에서 데이터를 쉽게 꺼내는 표현식
→ ${car.carName}, ${user.name} 등
→ 서버에서 전달받은 데이터를 화면에 출력할 때 사용

@정리@

Java  = 일을 처리
JSTL  = JSP에서 반복/조건 처리 
EL    = JSP에서 데이터 꺼내기

JSTL 이랑 EL 합쳐서 실무에서 많이씀. 코드도 JAVA에 비해 간략하게 쓸 수 있으니까 
JSTL 위주로 공부할것!!!
```
