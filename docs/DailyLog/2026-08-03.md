--객체생성--
Class 는 설계도 
ex) class Person{   }  ->   new Person(  ); 실제 객체 생성  

Class 안에  Person p1 = new Person(   );  <- 객체 생성   ->  참조변수(p1)가 객체를 가르킴 
p1은 참조변수 이름, new Person(); 으로 객체 생성

------------------------------------------------------------------------------------

--생성자--   +   -- this. --
class Person{

          String name;
           int age; 

      Person(String name, int age){

           this.name = name;
           this.age    = age;
   }

}

Person p1 = new Person("사람",12);

------------------------------------------------------------------------------------
--메소드--
객체    = 데이터 
메소드  = 기능 

객체   - "자동"실행
메소드 - "직접"불러야 실행 = 필요할때마다 사용하는 기능 

------------------------------------------------------------------------------------
--JVM 메모리 구조--
스택              (학생책상)        -> 객체를 가리키는 참조변수 '주소'
힙                (운동장)         -> 실체 객체와 객체의 '데이터'
메소드 에리어       (교무실)        -> 설계도(class)와 기능(메소드)

--static--
가족사진으로 이해 ㄱㄱ
가족사진을(static) 아빠(p1) 엄마(p2) 딸(p3)이 보고있는데,
딸(p3)이 가족사진(static)을 다른 가족사진으로 바꾸면,
아빠(p1) 엄마(p2) 딸(p3)도 다같이 다른 가족사진을 보게된다.
------------------------------------------------------------------------------------
--용어 정리--
-쉬운 말-	                -개발자 용어-
설계도	                    클래스(Class)
실제 물건	                객체(Object)
객체를 가리키는 이름표	      참조변수(Reference Variable)
객체 안에 들어있는 데이터	  객체변수(인스턴스 변수)
모두 함께 쓰는 공지사항	      static 변수
기능	                   메소드(Method)
값을 돌려준다	             return
객체가 만들어질 때 자동 실행   생성자(Constructor)
