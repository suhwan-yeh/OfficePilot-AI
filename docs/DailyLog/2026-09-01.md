## 1. JSTL

JSTL(JavaServer Pages Standard Tag Library)은 JSP에서 Java 코드를 직접 작성하지 않고 태그를 이용해 조건문, 반복문 등을 처리할 수 있도록 도와주는 라이브러리이다.

###  Core 태그 (`c:`)

```jsp
<c:set var="name" value="수환" scope="page"/>
```

* `set` : 변수 저장
* `remove` : 변수 삭제
* `if` : 조건문
* `redirect` : 페이지 이동
* `out` : 값 출력
* `choose` : 조건 분기
* `when` : 조건
* `otherwise` : 그 외 조건
* `forEach` : 반복문

###  Scope

`scope`는 데이터를 **어느 범위에서 사용할 것인지**를 의미한다.

```text
page        → 현재 JSP 페이지
request     → 하나의 요청
session     → 사용자 세션
application → 서버 전체
```

## 2. JSTL forEach

`c:forEach`는 JSP에서 반복문을 처리할 때 사용한다.

```jsp
<c:forEach var="member" items="${members}">
    ${member.name}
</c:forEach>
```

Java의 향상된 for문과 비슷한 개념이다.

```java
for(Member member : members) {
    System.out.println(member.getName());
}
```

따라서 **JSTL의 `forEach`와 Java의 향상된 for문을 연결해서 이해하기**.

또한 `loop.___` 형태의 여러 속성들은 `forEach`와 함께 사용되므로 같이 숙지하기.

## 3. JSTL Format (`fmt:`)

JSTL의 `fmt` 태그는 **국제화(I18N), 숫자 및 날짜 형식** 등을 처리할 때 사용한다.

###  국제화

```text
fmt:setLocale
      ↓
fmt:bundle
      ↓
fmt:message
```

사용자의 지역(Locale)에 따라 다른 언어로 메시지를 출력할 수 있다.

`fmt1.jsp`에서 국제화 코드의 기본 개념을 확인했다.

---

## 4. 숫자 형식

```jsp
<fmt:formatNumber 
    value="${price}" 
    groupingUsed="true"/>
```

`fmt:formatNumber`를 사용하면 숫자를 원하는 형식으로 출력할 수 있다.

특히 **`groupingUsed` 속성을 함께 사용하는 경우가 많음**.

예:

```text
1000000
↓
1,000,000
```

---

## 5. 날짜 형식

```jsp
<fmt:formatDate 
    value="${date}" 
    type="date"/>
```

`fmt:formatDate`를 사용하면 날짜를 원하는 형식으로 출력할 수 있다.

`type` 속성과 함께 사용하는 경우가 많다.
