## 오늘 배운것 
- MVC 구조
- 프로젝트 실행 흐름 
  JSP -> Controller -> Service -> DAO -> DB -> DAO -> Service -> Controller -> JSP 

### MVC 구조
```
Controller
    ↓
Service
    ↓
DAO
    ↓
Database
```
- Controller : 사용자의 요청을 받아 어떤 작업을 수행할지 결정. -> 로그인 요청이 들어왔다!
- Service : 실제 비지니스 로직 처리. -> 로그인 조건 확인 후 필요한 작업 수행 ㄱㄱ
- DAO : Datbase에 접근하여 SQL 실행. -> DB에서 회원정보 땡겨오자 
- VO : 회원 정보와 같은 데이터를 객체 형태로 담아 전달.
MemberVO
├─ id
├─ password                     -> 이런느낌 
├─ name 
└─ ...

### 프로젝트 실행흐름 정리 

``` 
┌──────────────────────┐
│      JSP / 화면       │
│   사용자가 보는 부분    │
└──────────┬───────────┘
           │
           │ HTTP 요청
           ↓
┌──────────────────────┐
│      Controller      │
│       요청 처리        │
└──────────┬───────────┘
           ↓
┌──────────────────────┐
│       Service        │
│      비즈니스 로직      │
└──────────┬───────────┘
           ↓
┌──────────────────────┐
│         DAO          │
│       DB 접근         │
└──────────┬───────────┘
           ↓
┌──────────────────────┐
│      Database        │
│       데이터 저장      │
└──────────────────────┘
```
### 쉽게 비유 
- JSP : 고객이 보는 창구 
- Controller : 접수 담당자
- Service : 업무 처리 담당자
- DAO : DB 담당자
- VO : 데이터를 담는 상자
- DB : 실제 데이터 저장소
