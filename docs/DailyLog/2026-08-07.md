### ArrayList 과정
- 생성
List<String> list = new ArrayList<>();
- 추가
list.add("사과");
list.add("바나나");
list.add("포도");
- 현재상태
[사과], [바나나], [포도]
- 꺼내기
system.out.println(list.get(0)); -> [사과] 
- 수정 
list.set(1, "딸기"); -> [사과], [딸기], [포도]
- 삭제
list.remove(0); -> [딸기], [포도]
- 갯수
list.size();
- 전체 출력 (향상된 for문)
for (String fruit : list) {
    System.out.println(fruit);
}
