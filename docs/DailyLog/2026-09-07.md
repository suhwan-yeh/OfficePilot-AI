##  jQuery AJAX 핵심 정리

### 1. jQuery 선택자

```javascript
$("#btn")       // id="btn"
$(".box")       // class="box"
$("button")     // button 태그
```

---

### 2. 클릭 이벤트

```javascript
$("#btn").on("click", 날씨조회);
```

→ 버튼을 클릭하면 `날씨조회()` 함수 실행

---

### 3. $.ajax()

jQuery에서 서버/API와 비동기 통신을 할 때 사용한다.

```javascript
$.ajax({
    url: "요청 주소",
    type: "get",
    data: {
        latitude: 위도,
        longitude: 경도
    },
    dataType: "json",

    success: function(response) {
        // 성공
    },

    error: function() {
        // 실패
    },

    complete: function() {
        // 항상 마지막 실행
    }
});
```

### 핵심

```text
url      → 어디로 요청?
type     → GET / POST?
data     → 무엇을 보낼까?
dataType → 무엇을 받을까?

success  → 성공
error    → 실패
complete → 항상 마지막
```

---

### 4. JSON 응답 처리

API에서 받은 데이터가:

```text
response
 └─ current
     ├─ temperature_2m
     ├─ relative_humidity_2m
     └─ wind_speed_10m
```

구조라면:

```javascript
const 현재 = response.current;

현재.temperature_2m
현재.relative_humidity_2m
```

처럼 접근한다.

---

### 5. 화면에 출력

```javascript
결과영역.html(html);
```

→ 만들어 놓은 HTML을 화면에 출력

```javascript

```

→ 일반 텍스트 출력
